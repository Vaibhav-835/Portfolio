## 🚀 Setup Instructions

1. **Clone the repo**

   ```
   git clone <your-repository-url>
   cd <repository-folder>
   ```
2. **Run locally:** open `index.html` in your browser.
3. **Deploy on Vercel**

   - Import the GitHub repo in Vercel.
   - Set Framework Preset to **Other** and leave Build Command and Output Directory empty.
   - Click **Deploy**.
